# v1 — held prototype

Two-week slice: a wizard you can actually talk to on a laptop. Hardware, face art, and a real parent phone come after.

## In

- Friend process: Realtime talk when `OPENAI_API_KEY` is set; fake transport when it isn't
- Frozen prompt as cacheable prefix (one personality)
- Sqlite memory that survives restart
- Five tools wired: `see` / `show` / `make` / `think` / `reach` (see/show/reach stubbed for camera, H3 Max, phone; `think` uses a reasoning model when `OPENAI_API_KEY` is set)
- State machine, interrupt, brevity
- Laptop mic + keyboard. Stick = click/hold keys
- Local print-look stills at 240×240. Screen-on only for show / saved page
- Tests for states, memory, tool allowlist, prefix assembly
- This monorepo layout, so the device is readable from the root

## Out (on purpose)

- ESP32-S3 firmware (`body/` is a README)
- Jun's hand-drawn face (`glass/` is a placeholder)
- Live parent-phone app (`reach/` is a local outbox)
- Cartesia mouth (interface only)
- Web search, extra tools, a second agent, a video player
- Photoreal, kid's face, third clip

## Pinecone is a use case

Walk it to test the verbs:

1. **Talk** — wake. Name, if we don't have it.
2. **See** — they point at a pinecone (inject a frame / hint on the laptop).
3. **Show** — still, then at most two clips, print look. Screen off. "Yeah. That's the whole spell."
4. **Make** — keep the page. "Yours. I don't lose stuff."
5. **Reach** — hold the stick. Page in the parent outbox.

Then put the pinecone down and talk about nothing. Ask why the sky is blue — he should **think**, not guess. If he dies, v1 is not done.
